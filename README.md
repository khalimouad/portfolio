# Nadine — Model Portfolio

A cinematic editorial model portfolio built with Next.js, Framer Motion and CSS. Deployable on Vercel.

## Add Nadine's photos

Upload the approved **unique** photos to `public/images/` with these filenames:

- `hero.jpg` — preferred champagne runway portrait
- `champagne-runway.jpg` — runway photo (can be a different angle)
- `burgundy-studio.jpg` — burgundy gown studio portrait
- `blue-caftan.jpg` — blue traditional runway look
- `red-beauty.jpg` — red beauty close-up
- `green-runway.jpg` — green gown runway
- `white-studio.jpg` — white top studio photo
- `casual-look.jpg` — striped casual outfit
- `beige-look.jpg` — beige suit outfit

The site shows graceful placeholders until images are uploaded. Do not upload duplicates. You can add more unique images by editing `gallery` in `app/page.tsx`.

## Customize

Update `stats` in `app/page.tsx` when waist, hips, shoe size and other measurements are confirmed. Replace the placeholder email `booking@example.com` with Nadine's approved booking email before launch. Add verified modeling credits in the Experience section.

## Run

`npm install` then `npm run dev`.

## Deploy

Import `khalimouad/portfolio` in Vercel; framework Next.js; default build settings.
